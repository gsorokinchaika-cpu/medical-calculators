# Медицинские калькуляторы v3.7

Приложение опубликовано на GitHub Pages:
[gsorokinchaika-cpu.github.io/medical-calculators](https://gsorokinchaika-cpu.github.io/medical-calculators/)

Готовая статическая сборка. Одного `index.html` недостаточно: стили, скрипт и изображения находятся в `assets/`. Для офлайн-режима нужен HTTPS (или localhost при разработке); открытие через `file://` не поддерживает service worker.

## Проверки

- 48 автоматических тестов для версии 3.7;
- синтаксис JavaScript;
- уникальность `id`, наличие DOM-ссылок, якорей и локальных ресурсов;
- автоматические тесты 30 инструментов: контрольные примеры, границы категорий, единицы, навигация и отказы на некорректных данных;
- SCORE2-Diabetes: восемь результатов авторского Excel для обоих полов / четырёх регионов и семь согласованных примеров из текста статьи;
- SCORE2-OP: независимая двухэтапная реализация таблиц приложения, 640 комбинаций входных данных (не клиническая валидация);
- изоляция офлайн-кэша, работа без сети, отказ неполной установки и явное согласие на обновление;
- четыре опубликованных примера SCORE2 для обоих полов и двух регионов, независимые единицы холестерина и выбор категории по двум версиям рекомендаций;
- отсутствие встроенных base64-изображений и корректность путей к ресурсам.

Тесты не требуют дополнительных библиотек:

```sh
node --check assets/app-7a53f8f987.js
node --check sw.js
```

GitHub Actions запускает эти проверки при push и pull request. Это регрессионная проверка программного поведения, **не независимая клиническая валидация всех шкал**. Успешный базовый сценарий сам по себе не доказывает соответствие всему клиническому стандарту.

Также проверены в браузере: экраны 320, 390, 768 и 1280 пикселей без горизонтального переполнения; мобильный поиск SCORE2-Diabetes; перенос в один выбранный калькулятор без перезаписи; перевод единиц; очистка для нового пациента; загрузка новой версии и полный запуск с расчётом SCORE2-Diabetes после остановки локального сервера. Проверка в конкретном Telegram WebView и сравнение с закрытым U-Prevent (требует аккаунт) не выполнялись.

## Что нового

Спокойный компактный интерфейс, светлая и тёмная темы, избранное, ссылки на отдельные калькуляторы и быстрый поиск (`Ctrl/Cmd + K`). На телефоне доступны поиск, категории и возврат к избранному. Медицинские данные не записываются в localStorage и не включаются в ссылки; сохраняются только тема и идентификаторы избранных инструментов. Нажатие «Копировать результат» явно копирует текст расчёта в системный буфер обмена.

### Общие данные

Сворачиваемая панель переносит показатели только по кнопке, только в пустые совместимые поля и с учётом выбранных единиц. Можно выбрать один калькулятор или все совместимые. Введённые в калькуляторах значения не заменяются; клиническую применимость нужно подтвердить отдельно. Возраст и другие ограничения остаются на уровне каждой формулы. Общая СКФ CKD-EPI 2021 используется только в PREVENT: в SCORE2-Diabetes требуется отдельно указать СКФ CKD-EPI 2009 по креатинину, как в исходной модели. «Новый пациент» очищает все формы и результаты после подтверждения; тема и избранное остаются.

### Офлайн и обновления

После первого полного открытия с интернетом дождитесь надписи «Доступно офлайн». Service worker кэширует только четыре публичных файла: HTML, JS, CSS и аватар. Введённые данные и результаты в кэш не попадают и теряются при перезагрузке. Внешние ссылки, официальный FRAX и страницы источников требуют интернет. Некоторые встроенные браузеры (включая отдельные версии Telegram) могут не поддерживать офлайн-режим — в таком случае откройте сайт в обычном браузере. Браузер может очистить кэш при нехватке места.

Новая версия не перезагружает текущий расчёт автоматически. Кнопка обновления предупреждает об очистке введённых данных. Офлайн доступна последняя загруженная версия; номер и дата сборки показаны сверху. `_headers` применяется только хостингами, поддерживающими этот файл, не GitHub Pages.

При выпуске изменяйте имена JS/CSS по хэшу содержимого, ссылки в HTML/проверках и список `FILES` в `sw.js`. `VERSION` в worker должен быть уникальным для каждой сборки, включая изменения одного HTML: одинаковое имя кэша у старой и новой версии недопустимо.

## SCORE2: источники и различия результатов

- Численная модель и точные коэффициенты: [EHJ 2022, ehab761](https://doi.org/10.1093/eurheartj/ehab761).
- Контрольные примеры: [исходная публикация SCORE2, ehab309](https://doi.org/10.1093/eurheartj/ehab309).
- Кластеры стран и возрастные категории профилактики: [ESC 2021, ehab484](https://doi.org/10.1093/eurheartj/ehab484).
- Категории для ведения дислипидемий: [ESC/EAS 2025, таблица EAS](https://eas-society.org/publications/guidelines/score2-score2-op/).

Смена версии интерпретации меняет категорию, не рассчитанный процент. Калибровка по стране меняет процент. Численная модель использует общий холестерин и ЛПВП раздельно; округлённые табличные диаграммы могут давать другое значение. Обычный SCORE2 ограничен возрастом 40–69 лет и указанными в форме условиями применимости.

### SCORE2-OP и SCORE2-Diabetes

- [SCORE2-OP, ehab312](https://doi.org/10.1093/eurheartj/ehab312): Supplementary Methods Table 1 — калибровка, Tables 2–3 — центрирование, baseline survival и точные коэффициенты. Возраст 70–89 лет; в приложении — первичная профилактика без ССЗ, диабета, ХБП и генетических нарушений липидов/АД. Категории ESC 2021 для ≥70 лет: 7,5% / 15%; ESC/EAS 2025 — отдельная интерпретация.
- [SCORE2-Diabetes, ehad260](https://doi.org/10.1093/eurheartj/ehad260): Supplementary Table 1 и авторский Excel Appendix 2. Ограничение 40–69 лет / СД2 / отсутствие ASCVD и тяжёлого поражения органов-мишеней — по [ESC 2023, ehad192](https://doi.org/10.1093/eurheartj/ehad192). СКФ <45, СКФ <60 с A2, A3 или неизвестная альбуминурия блокируют расчёт. Наличие других форм тяжёлого поражения оценивает специалист.
- HbA1c переводится по [мастер-уравнению NGSP/IFCC](https://ngsp.org/ifccngsp.asp), не по приблизительной таблице. Статус курения и пол не подставляются заранее.

**Известные расхождения внутри первоисточников:** в SCORE2-OP текстовые примеры Table 3 используют другие scale1/scale2, чем Table 1, и содержат несогласованные знаки LP. Здесь используется Table 1 и явно записанная формула из Table 2. Для SCORE2-Diabetes первый женский пример в тексте статьи даёт 7,9%, тогда как точные коэффициенты и авторский Excel дают 7,588…% (7,6% на экране). Остальные семь перечисленных примеров согласуются. Формула не подгонялась под противоречащие ей примеры. Проверка против авторских материалов не равна независимой клинической валидации или сертификации; перед клиническим применением нужна экспертная проверка, особенно для SCORE2-OP.

FIB-4: ограничение точности до 35 лет отражено в результате, а не только в примечании; [AASLD Practice Guidance 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10735173/).

Важно: приложение помогает выполнять математические расчёты, но не заменяет клиническое решение. Перед использованием результата проверьте исходные данные, единицы измерения и применимость формулы.
