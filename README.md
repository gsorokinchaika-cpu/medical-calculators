# Медицинские калькуляторы v3.6

Приложение опубликовано на GitHub Pages:
[gsorokinchaika-cpu.github.io/medical-calculators](https://gsorokinchaika-cpu.github.io/medical-calculators/)

Готовая статическая сборка. Открывайте `index.html` локально или загружайте всю папку целиком в существующий проект Netlify. Одного `index.html` недостаточно: стили, скрипт и изображения находятся в `assets/`.

## Проверки

- синтаксис JavaScript;
- уникальность `id`, наличие DOM-ссылок, якорей и локальных ресурсов;
- 28 автоматических тестов, включая базовый успешный сценарий каждого из 28 инструментов, контрольные примеры, границы категорий, навигацию и отказы на некорректных данных;
- четыре опубликованных примера SCORE2 для обоих полов и двух регионов, независимые единицы холестерина и выбор категории по двум версиям рекомендаций;
- отсутствие встроенных base64-изображений и корректность путей к ресурсам.

Тесты не требуют дополнительных библиотек:

```sh
node --check assets/app-906a18c247.js
node --test tests/calculators.test.mjs
```

GitHub Actions запускает эти проверки при push и pull request. Это регрессионная проверка программного поведения, **не независимая клиническая валидация всех шкал**. Успешный базовый сценарий сам по себе не доказывает соответствие всему клиническому стандарту.

## Что нового

Спокойный компактный интерфейс, светлая и тёмная темы, избранное, ссылки на отдельные калькуляторы и быстрый поиск (`Ctrl/Cmd + K`). На телефоне доступны поиск, категории и возврат к избранному. Медицинские данные не записываются в localStorage и не включаются в ссылки; сохраняются только тема и идентификаторы избранных инструментов. Нажатие «Копировать результат» явно копирует текст расчёта в системный буфер обмена.

## SCORE2: источники и различия результатов

- Численная модель и точные коэффициенты: [EHJ 2022, ehab761](https://doi.org/10.1093/eurheartj/ehab761).
- Контрольные примеры: [исходная публикация SCORE2, ehab309](https://doi.org/10.1093/eurheartj/ehab309).
- Кластеры стран и возрастные категории профилактики: [ESC 2021, ehab484](https://doi.org/10.1093/eurheartj/ehab484).
- Категории для ведения дислипидемий: [ESC/EAS 2025, таблица EAS](https://eas-society.org/publications/guidelines/score2-score2-op/).

Смена версии интерпретации меняет категорию, не рассчитанный процент. Калибровка по стране меняет процент. Численная модель использует общий холестерин и ЛПВП раздельно; округлённые табличные диаграммы могут давать другое значение. Обычный SCORE2 ограничен возрастом 40–69 лет и указанными в форме условиями применимости; SCORE2-OP и SCORE2-Diabetes пока не реализованы.

FIB-4: ограничение точности до 35 лет отражено в результате, а не только в примечании; [AASLD Practice Guidance 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10735173/).

Важно: приложение помогает выполнять математические расчёты, но не заменяет клиническое решение. Перед использованием результата проверьте исходные данные, единицы измерения и применимость формулы.
